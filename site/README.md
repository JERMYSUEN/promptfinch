# PromptFinch Product Site

Zero-dependency static product landing page ready for **GitHub Pages**, **Cloudflare Pages**, or **Netlify**.

## Preview Locally

```sh
npx serve site
# or
python3 -m http.server -d site 4173
```

Open `http://127.0.0.1:4173` in your browser. Supports automatic Light/Dark theme switching, bilingual toggle (`繁體中文` / `English`), and interactive Before → After prompt refinement previews.
