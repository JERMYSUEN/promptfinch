# 任務優化與翻譯的區別

本頁記錄 2026-10-15 的規則、檢查與失敗請求，不是模型供應商的即時服務狀態；後續是否恢復需重新測試。一般操作與模型設定見[文件索引](README.md)及 [macOS 指南](macos.md)。

日期：2026-10-15。本次更新要求模型改善指令的可執行性，而不只是翻成英文。繁中與英文模式均採用這個原則；英文模式仍保留使用者指定的下游答案語言。

## 改動與範圍

- 從散亂需求辨識目標、材料、限制、指代與先後依賴，按需要整理執行順序。
- 允許補充完成同一任務的方法，例如把「確認修好了」轉成針對原有行為的驗證。禁止擅自新增事實、技術選擇、受眾、期限、數量、格式或交付物。
- 已明確的小任務可以只做最小編輯；不強制角色、分節、流程或檢查表。JSON only、code only 等輸出限制仍優先，必要核對在交付前進行。
- 「先看目前專案」是要求下游代理檢視其工作目錄，不因原文未貼程式碼就一律要求使用者補檔。只有無法存取專案時才索取相關檔案或存取方式，不能假裝已完成檢視。
- 改善說明必須對應實際改動。若只有翻譯或潤飾，不得宣稱加入了不存在的優化。

這是編輯指令的模型策略，沒有新增會任意擴充使用者需求的固定文字後處理。原有輸入驗證、結構化回應、金鑰處理、mock 標示與不儲存一般需求／結果的行為維持原樣。

## 示範中的具體價值

Codex GIF 的原始粗稿為：

> 幫我修這個專案 CSV 去重的 bug。email 大小寫要當同一個，留第一筆，順序和標頭不要動。先看現有寫法再改，改完確認修好了，用繁體中文簡單講。

示範的優化指令分為 Goal、Approach、Verify & report：先定位現有實作並聚焦修改，再用大小寫不同的重複 email 與不同 email 檢查首筆保留、標頭與列順序。這些方法直接服務原本的錯誤修正目標，沒有指定新程式語言、套件或額外功能。

動畫中的英文結果是人工編寫的合成示例，用來說明期望的編輯效果，不是模型生成紀錄或品質驗證。Codex 介面、選取、選單與游標均為重製，沒有使用私人影片或對話，也沒有送出聊天。

## 驗收準則與真實模型限制

[8 個合成案例](../tests/fixtures/optimization-value.json)涵蓋六類任務，以及繁中、英文、日文與韓文操作指令。每案都有保真與任務改善判準，包含完整簡單指令的「保持精簡」對照。

人工覆核必須同時檢查：是否保留原意、限制與答案語言；是否加入有根據的操作改善；是否避免新增任務或直接作答；改善說明是否如實。不能用英文流暢、輸出變長、出現標題或 HTTP 200 代替這些判準。

本次沿用已設定的 `deepseek-flash`，沒有切換供應商。真實模型測試遇到服務失敗：

| 時點 | 案例 | 實際結果 |
| --- | --- | --- |
| 更新前 | 繁中通知 | HTTP 504，約 90 秒逾時，無可用結果。 |
| 更新前 | CSV 錯誤修正 | HTTP 502，服務暫時無法使用，無可用結果。 |
| 更新後 | 同一 CSV 案例 | HTTP 502，服務暫時無法使用，無可用結果。 |

更新前批次在連續失敗後中止，中止時未完成的案例沒有算作通過，也沒有繼續發出整批請求。其餘案例尚未完成。沒有取得可供語意比較的真實模型輸出，因此**不能宣稱新規則已證明優於原版**，也不能將示意動畫當成模型實測。[失敗與中止紀錄](optimization-value-results.json)保留已回傳的合成請求資料與版本識別；未取得供應商帳單，不宣稱精確費用。

## 重現

先依 README 設定自己的模型服務。下列 live 指令會送出合成案例，可能產生費用；服務持續失敗時應停止批次，避免無效重試。

```sh
npm run check
npm test
node scripts/check-readmes.js
npm run package:source

# 先以單案確認服務可用，再決定是否執行整批。
node scripts/verify-multilingual.js --live \
  --cases tests/fixtures/optimization-value.json \
  --ids value-coding-zh-csv-dedup \
  --output artifacts/optimization-value/coding-recheck.json

node scripts/verify-multilingual.js --live \
  --cases tests/fixtures/optimization-value.json \
  --output artifacts/optimization-value/all-cases.json
```

runner 逐案保存結果，必要字串遺失或請求失敗會以非零退出。語意覆核仍是獨立步驟；mock 沒有翻譯或語意優化能力。
