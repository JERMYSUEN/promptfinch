# 跨語言英文 Prompt 對照驗證

版本限定的驗證紀錄：本頁分別列出多個後端，不是最新 `main` 的整體通過報告。後續模型規則及未成功的真實 API 比較見[任務優化驗證](optimization-value-verification.md)；操作與設定見[文件索引](README.md)。

日期：2026-10-15。模型沿用使用者已設定的 `deepseek-flash`，沒有換模型、共用金鑰或付費備援。全部輸入都是新建的非敏感合成案例。正常工作台仍不儲存需求或結果；本頁與 JSON 是刻意保存的測試紀錄。

## 本次改動

- 英文模式使用英文用途 ID 與用途提示，未指定目標模型時傳空值。這可移除中文用途 metadata 對模型判斷的干擾來源，但不保證消除語言誤判；繁中 API 契約維持相容。
- 保留既有英文編輯保護，補強原語語意、口語、羅馬化文字、條件／否定作用範圍及數值單位。沒有加入依字母表猜答案的語言特規。
- 用完整 JSON 範例區分明示答案語言、推定答案語言、長引文與混語待釐清。英文指令、下游答案語言、繁中介面說明各有不同用途。
- 補強先讀完原文再判斷資料是否缺漏：已提供的事實不應被佔位符取代，也不應為每個文案變體索取一項新功能。缺資料時的「先問並暫停」須保留條件範圍。
- 修正驗證工具：必要字串遺失也會以非零退出；新增 `--ids` 精確選案及請求前驗證。字串通過後仍標為待語意覆核。

## 同一組判準

[主矩陣](../tests/fixtures/multilingual-parity.json)有 35 案：29 個 locale、28 種語言，中文分繁簡。29 案使用相同目的與已提供的「新增離線搜尋」事實；另 6 案測缺少功能資訊時先問一題並等待。

共同要求包含：英文可複製指令、日文通知、恰好 3 則、每則正文最多 60 個字元且標題不計入、JSON 陣列、`title`／`body` 鍵與產品名逐字保留、友善語氣、不編造日期／價格／其他功能。生成器不能直接代寫通知。

[語言邊界案例](../tests/fixtures/multilingual-language-edges.json)另有 8 案，涵蓋韓文答案語言推定、日文操作搭配長英文資料、西語口語與已確認價格、日英混語明示韓文、羅馬化 Hindi、沒有明確主導語言的混語、待翻譯引文內的指令，以及俄文條件與欄位字元範圍。

## 尚有限制

- 沒有明確主導語言且未指定答案語言的混語，模型仍可能自行選語言。若答案語言重要，請在原始需求中明確指定。
- 部分繁中條件句改寫後，末句的「不要直接撰寫」仍可能被理解為無條件禁止交付；需要人工檢視條件範圍。
- 改善與假設說明仍可能漏記或誤記語言推定。它們不會附加到可複製 Prompt，仍需與原文及主 Prompt 分開檢視。
- 每個案例是有限次取樣；不能保證所有輸入、方言、任務或模型均與中文完全等效。低資源語言語料尚未經母語者校閱。

## 程式與部署檢查

`npm run check`、驗證腳本語法及 64 項 Node 測試通過。測試包含 29 locale 的一致判準與完整傳輸、英文／繁中 metadata 契約、字串遺漏退出碼、零請求選案錯誤、mock 拒絕與完整結果保存。可控服務沒有翻譯能力，這些測試不算真實模型品質證據。

已執行 `npm run update:mac-backend`，經隔離 mock HTTP 預檢與版本核對後更新 App 管理的後端，保留既有模型設定。一次本機預檢沒有收到完整 JSON，當次未切換版本，重跑後成功。這次沒有修改原生介面，也沒有重跑原生或瀏覽器 UI 套件。

## 重現與費用

主矩陣 35 案、邊界 8 案共 43 個不同案例。本次各版本、基準與有限重測合計 115 次工作台 HTTP 優化請求。後端仍可能對格式失敗多嘗試一次，因此 HTTP 次數不等於供應商請求或計費數；未取得帳單，不宣稱精確費用。

以下 live 指令會使用自己的模型設定並可能計費。只使用合成資料；不要將含私人內容的結果提交到版本庫。

```sh
npm run check
npm test
node --check scripts/verify-multilingual.js

node scripts/verify-multilingual.js --live \
  --cases tests/fixtures/multilingual-parity.json \
  --output artifacts/parity-results.json

node scripts/verify-multilingual.js --live \
  --cases tests/fixtures/multilingual-language-edges.json \
  --ids language-edge-ko-inferred-answer,language-edge-ja-long-english-source \
  --output artifacts/language-edge-results.json
```

每個 runner 會循序呼叫、逐筆保存並把語意覆核保留為 `pending`。來源不同語言不會使用不同的模型、額外翻譯服務或測例答案。必要字串遺漏或請求失敗會讓 runner 失敗退出；其餘語意仍需逐項閱讀。
