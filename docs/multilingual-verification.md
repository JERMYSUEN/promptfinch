# 多語輸入與英文 Prompt 驗證

日期：2026-10-09。實測模型：使用者既有 `deepseek-flash` 設定。全部輸入為固定、非敏感合成測例；沒有換模型、共用金鑰、付費備援、影片／圖片生成或執行原任務。

## 支援範圍與證據

輸入接受 Unicode，沒有來源語言或字母表白名單。韓文與俄文是必要涵蓋語言。README 的 29 個語言／書寫版本對應 28 種語言，是文件及涵蓋目標，不代表 App 已翻譯成 28 種介面，也不代表每個模型都能正確處理每種語言。App 介面及改善／假設說明維持繁體中文。

本輪最終語料共 24 個不同案例、18 種來源語言：英、中文（繁／簡兩種書寫形式）、日、韓、俄、西、法、德、葡、義、烏克蘭、阿拉伯、波斯、印地、孟加拉、泰、越、印尼。另有一例以英文操作指令測韓俄固定字串、NFD 重音、emoji、變數與 URL；這一例只證明混字串保留，不能替代韓俄語意實測。

土耳其、荷蘭、波蘭、泰米爾、泰盧固、馬拉地、烏爾都、斯瓦希里、旁遮普、菲律賓文仍為未在本輪 live 測試的目標。多數代表案例是短寫作需求；這不是複雜領域、所有方言、所有語言、所有模型或所有宿主 App 的保證。

證據分成三種：

1. **接線與邊界**：檢查原文、JSON、UTF-8 分段回應、Mac 編碼與選取範圍是否完整。可控服務回應沒有真正的翻譯能力。
2. **真實模型結果**：實際向既有模型送出固定需求，記錄完整英文 Prompt、獨立說明、HTTP 狀態與逐字檢查。HTTP 200 本身不是語意通過。
3. **人工語意覆核**：Codex 對照來源需求及指定判準逐項閱讀指令，確認任務、答案語言、否定範圍、數字與輸出形式。這不是母語專家認證或 IDE 實機驗收。

完整來源、最終 Prompt、判讀及各階段歷史見 [完整測例結果](multilingual-live-results.json)。修正前及中間結果另外保留在本機測試產物，沒有用最終結果掩蓋初始失敗。

## 發現與通用修正

- 簡體案例曾回傳中文指令：加強指令語言與下游答案語言的區分，user data 明示 `promptInstructionLanguage`，網頁提供英文／繁中切換。API 省略 `promptLanguage` 仍維持 `zh-Hant`。
- NFD 固定字串曾被模型變成 NFC：輸入本身不正規化；英文結果只針對來源中明確、不歧義的引文／程式碼字面還原等價編碼，不猜漏字、不翻譯、不還原普通敘述。還原後超過回應上限仍拒絕，沒有截短。
- 韓文短摘要曾缺少來源條件；加強未提供摘要／分析來源時的具名佔位符與先索取指令，與可重用模板、程式路徑佔位符區分。
- 俄文程式需求曾被路徑佔位符阻擋；現可直接撰寫程式，驗證資料必須明示合成，不能假裝讀過使用者檔案。
- 多例把明示答案語言列成假設；補上跨語言範例與說明判準，重測相關案例。缺少來源也不屬於假設。
- 西語「不得編造」曾被加嚴成「不得包含」；新增通用否定範圍規則，西／葡／義實測確認區分。
- 韓文長案例曾漏初學者受眾；補強保留原文受眾與解說程度的規則，再單獨重測。

以上修正不是用韓俄關鍵字猜答案的硬碼；模型仍負責理解所有來源語言。NFC字面還原是範圍有限的編碼保護，不能驗證語意或補救所有改寫錯誤。

## 重現方式與費用

先啟動已設定的工作台或Mac App。下列指令會呼叫使用者選定的真實模型，可能計費；輸出檔是刻意保存的測試產物，和正常工作台不保存內容的行為不同。不要用私人內容替換公開測例再提交。

```sh
npm run check
npm test
npm run test:mac
PLAYWRIGHT_CHANNEL=chrome npm run test:ui

# 每次各6例／18例，順序執行；--live必須明確提供。
node scripts/verify-multilingual.js --live --cases tests/fixtures/multilingual-ko-ru.json --output artifacts/ko-ru-recheck.json
node scripts/verify-multilingual.js --live --cases tests/fixtures/multilingual-inputs.json --output artifacts/representative-recheck.json
# 若使用standalone服務，另加 --url http://127.0.0.1:3000
```

腳本只連本機工作台，檢查 `live/ready`，逐例執行、有逾時，不在console印原文、結果或金鑰。模型回應仍可能變動，需重新語意覆核。後端格式不符最多重試一次；沒有切換其他免費／付費模型。無金鑰時請用明示mock檢查流程，不能跑出假裝真實的翻譯測試。
