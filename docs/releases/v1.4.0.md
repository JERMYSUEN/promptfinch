# PromptFinch v1.4.0

This release introduces the zero-Node **Native Direct multi-provider engine** on macOS (with Keychain credentials and real SSE token streaming), a **miniaturized macOS & Electron UI** (Selection Micro-Pill, dynamic floating Result Card with inline editing notes & quick style rerun, 356 px Menu-Bar Popover with 1-click model switching, and always-on-top Mini Mode), an **interactive model version selector with live `/models` discovery**, opt-in **Local Secret Shield**, and a **Manifest V3 browser extension** for ChatGPT, Claude, Gemini, GitHub, Notion, and Perplexity.

## Downloads and setup

Download the package for your platform from [v1.4.0](https://github.com/JERMYSUEN/promptfinch/releases/tag/v1.4.0):

Matching checksum files (`SHA256SUMS` / platform `SHA256SUMS-*.txt`) and verification manifests accompany the packages. Public desktop packages remain ad-hoc signed or unsigned without Apple Developer ID notarization or Windows publisher signing. Recorded native macOS verification was run on Apple Silicon; Intel Macs and the minimum macOS 13 target have not been physically validated. Linux builds target Ubuntu 22.04 x86_64-compatible glibc distributions; X11 selection is experimental and Wayland uses manual input/clipboard import.

On macOS, Native Direct mode connects straight to your chosen model provider using macOS Keychain with no external Node.js installation. Users upgrading a legacy `.env` backend install can either switch to Native Direct mode in **Settings → Model**, or select **Settings → Model → Local Node.js .env backend → Use this app's bundled backend** to adopt the updated optimizer while preserving their private `.env` file. See the [macOS guide](../macos.md) and [extension guide](../../extension/README.md).

## Key highlights in v1.4.0

- **Zero-Node Native Multi-Provider Engine & Keychain Security**: macOS connects directly to DeepSeek, OpenAI, Anthropic Claude (with ephemeral prompt caching), Google Gemini, local Ollama, and custom OpenAI-compatible endpoints without requiring Node.js 22+. API keys are stored encrypted in macOS Keychain (and `0600` private `.env` files on Electron).
- **Real SSE Token Streaming**: Native Swift (`URLSession.bytes`) and Node (`POST /api/optimize/stream`) stream clean incremental `"prompt"` previews across OpenAI/DeepSeek, Anthropic, and Gemini while hiding raw JSON scaffolding until final strict validation completes.
- **Interactive Model Version Selector & Live `/models` Discovery**: Curated model menus clarify exact versions (such as `deepseek-flash` = DeepSeek-V4.1-Flash, alongside `deepseek-v4-pro`, `deepseek-chat`, `deepseek-reasoner`, OpenAI GPT-4.1/GPT-5, Claude 4.5/5.5, Gemini 2.5/3.x, and Ollama models), paired with live `/models` fetching and automatic per-model `thinkingMode` resolution.
- **Miniaturized UI & Instant Controls**:
  - macOS Selection Micro-Pill (`~106×28 pt`), dynamic-height `410 pt` Result Card with live streaming, inline collapsible editing notes, quick style switching (`balanced` / `concise` / `structured`), one-click rerun, and clipboard-preserving paste-back.
  - 356 px Menu-Bar Popover with 1-click quick model switching, refinement styles, and in-memory session history, plus Menu-Bar-Only (`.accessory`) mode, compact 4-tab Settings, and macOS/Electron floating Mini Window Mode.
- **Local Secret Shield & Manifest V3 Browser Extension**: Opt-in local redaction masks API keys, GitHub/AWS tokens, JWTs, and PEM private keys before sending and restores them locally. The new MV3 extension brings in-page refinement directly into ChatGPT, Claude, Gemini, GitHub, Notion, and Perplexity with zero OS permissions.

## Validation and previous releases

Automated checks cover 162 Node tests (`npm test`), full Swift native regression tests (`npm run test:mac`), 28-locale README parity (`npm run check:docs`), Electron Windows/Linux CI builds (`desktop.yml`), Universal macOS packaging (`release-macos.yml`), Chrome extension archive packaging (`npm run package:extension`), and isolated mock HTTP package verification (`npm run check:package`).

Earlier release tags (`v1.0.0`, `v1.1.0`, `v1.2.0`, `v1.3.0`) and their published assets remain untouched historical snapshots. There is no automatic updater.
