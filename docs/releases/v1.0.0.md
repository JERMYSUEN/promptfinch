# PromptFinch v1.0.0 — First public release

PromptFinch edits rough requirements into clearer prompts for writing, coding, research, summarization and planning. It edits the instructions; it does not perform the original task.

For the current app download and newer features, use **[PromptFinch v1.1.0](https://github.com/JERMYSUEN/promptfinch/releases/tag/v1.1.0)** and its [upgrade instructions](https://github.com/JERMYSUEN/promptfinch/blob/main/docs/releases/v1.1.0.md). This original tag and attached asset remain unchanged.

This release is the **2026-10-10 snapshot at tag `v1.0.0`**. The attached download has not been rebuilt for later commits on `main`. Terminal copy-only handling, the newer multilingual rules and the current synthetic Codex demo were added after this tag. Use the newer release linked above or [current source](https://github.com/JERMYSUEN/promptfinch) for those changes; consult the [changelog](https://github.com/JERMYSUEN/promptfinch/blob/main/CHANGELOG.md) before choosing a version.

## Features in this release

- A native macOS workspace and selection assistant, plus an optional browser workspace and HTTP API using the same backend.
- Six task types: general, writing, analysis, coding, summary and marketing. The optional target-model field guides the wording; the configured backend model generates the result.
- Select text in a compatible app, right-click, then choose **Convert to English prompt** in PromptFinch's separate companion action menu. Right-clicking alone does not call the model. A selection button, supported macOS Services, **⌥⌘P**, and explicit clipboard input are additional entry points.
- Review the result, copy it, or request paste-back when the app exposes a verified editable selection. Compatibility depends on the host and Accessibility access; this is not a promise of support in every app. No chat message is automatically submitted.
- Native UI in Traditional Chinese, English, Japanese and Korean. The browser UI is Traditional Chinese; its prompt instructions can be Traditional Chinese or English. The native app produces English instructions. All modes are designed to retain the original requested answer language and required literals; review generated text before use.
- Separate prompt, improvement notes and assumptions. The prompt follows the task's required format, rather than a mandatory fixed outline.
- Server-side OpenAI-compatible Chat Completions calls with your own credentials, plus a clearly labeled mock mode for checking the workflow without a model. No model or API key is included.

## Download and requirements

The attached `PromptFinch-1.0.0-macos-arm64.zip` is an **Apple Silicon** app for macOS 13 or later. It contains the Node backend source, **not the Node runtime**: install Node.js 22 or later separately. Select the Node executable in the app's settings if automatic discovery cannot find it.

This is not a Developer ID-signed, notarized distribution. macOS may block an untrusted downloaded app; assess the source and use macOS's own security controls if you choose to run it. Local source builds are an alternative. A personal signing certificate is for your own update continuity and does not establish publisher trust or notarization.

The release/tag/package version is `1.0.0`; the tagged app's internal bundle version is `0.1.0`, build `11`. This documentation correction does not replace the original download or retag it.

## Build from the release source

Requires Node.js 22+, macOS 13+, and Apple's Xcode Command Line Tools. These commands build the tagged release, not latest `main`:

```sh
git clone --branch v1.0.0 https://github.com/JERMYSUEN/promptfinch.git
cd promptfinch
xcode-select --install  # Skip if the tools are already installed.
npm run setup:signing:mac  # Optional personal local signing identity.
npm run build:mac
npm run install:mac
```

`install:mac` copies and opens the existing build; it does not build it. Runtime use and native builds do not need `npm install`, because the backend has no runtime dependencies. Run `npm ci` when installing the development/browser-test dependencies.

Use the app's Settings to select or create a private model configuration file. To try the interface without credentials, choose demo mode. A real model needs `OPTIMIZER_MODE=live`, `LLM_API_KEY`, `LLM_MODEL` and a compatible `LLM_BASE_URL`; consult the [macOS setup guide](https://github.com/JERMYSUEN/promptfinch/blob/main/docs/macos.md) for the available settings. Never put a key in a prompt or commit it.
