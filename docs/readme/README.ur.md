## اردو

PromptFinch لکھنے، کوڈنگ، تحقیق، خلاصوں اور منصوبہ بندی کے لیے پرامپٹ ایڈیٹر اور بہتر بنانے والا ٹول ہے۔ کسی بھی زبان میں ہدایات درج یا منتخب کرکے انگریزی پرامپٹ بنائیں۔ واضح تقاضے، جواب کی مطلوبہ زبان اور اقتباسی علامات میں موجود مقررہ متن برقرار رہتے ہیں۔

macOS ایپ میں دستی ورک اسپیس اور منتخب متن کا معاون ہے؛ مطابقت رکھنے والی ایپس میں متن منتخب کریں، دایاں کلک کریں، پھر معاون مینو سے **Convert to an English Prompt** منتخب کرکے نتائج دیکھیں۔ براؤزر ورک اسپیس بھی دستیاب ہے۔ حقیقی جنریشن کے لیے ماڈل کی API کلید ترتیب دینا ضروری ہے۔ Mock صرف عمل کا پیش منظر دکھاتا ہے، ترجمہ یا بہتری نہیں کرتا۔ انٹرفیس روایتی چینی میں ہے؛ یہ صرف دستاویزات کا ترجمہ ہے۔

**طریقہ:** ہدایات درج یا منتخب کریں، پرامپٹ بنائیں، پھر جائزہ لے کر کاپی کریں۔
