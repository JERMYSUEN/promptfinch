## اردو

PromptFinch لکھنے، کوڈنگ، تحقیق، خلاصوں اور منصوبہ بندی کے لیے پرامپٹ ایڈیٹر اور بہتر بنانے والا ٹول ہے۔ کسی بھی زبان میں ہدایات درج یا منتخب کرکے انگریزی پرامپٹ بنائیں۔ یہ واضح تقاضوں، جواب کی مطلوبہ زبان اور اقتباسی علامات میں موجود مقررہ متن کو برقرار رکھنے کے لیے بنایا گیا ہے۔

macOS ایپ میں دستی ورک اسپیس اور منتخب متن کا معاون ہے؛ مطابقت رکھنے والی ایپس میں متن منتخب کریں، دایاں کلک کریں، پھر معاون مینو سے **Convert to English prompt** منتخب کرکے نتائج دیکھیں۔ براؤزر ورک اسپیس بھی دستیاب ہے۔ حقیقی جنریشن کے لیے ماڈل کی API کلید ترتیب دینا ضروری ہے۔ Mock صرف عمل کا پیش منظر دکھاتا ہے، ترجمہ یا بہتری نہیں کرتا۔

macOS کی سیٹنگز میں انٹرفیس کے لیے روایتی چینی (پہلے سے منتخب)، انگریزی، جاپانی یا کوریائی منتخب کی جا سکتی ہے۔ براؤزر کا انٹرفیس روایتی چینی میں ہی رہتا ہے۔ ماڈل سے بہتری اور مفروضوں کے نوٹس روایتی چینی میں لکھنے کی درخواست کی جاتی ہے؛ انٹرفیس کی زبان بدلنے سے ان کا ترجمہ نہیں ہوتا۔ README کے زبان کے لنکس صرف دستاویزات کے صفحات بدلتے ہیں۔

**طریقہ:** ہدایات درج یا منتخب کریں، پرامپٹ بنائیں، پھر جائزہ لے کر کاپی کریں۔
