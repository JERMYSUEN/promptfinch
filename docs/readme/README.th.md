# PromptFinch

> หน้านี้เป็นคำแปลส่วนแนะนำ เอกสารทางเทคนิคฉบับเต็ม รวมการติดตั้งและ API อยู่ใน [English](../../README.md#english)

## เกี่ยวกับ PromptFinch

PromptFinch คือเครื่องมือแก้ไขและปรับปรุงพรอมป์ต์สำหรับงานทั่วไป ป้อนหรือเลือกคำสั่งภาษาใดก็ได้เพื่อสร้างพรอมป์ต์ภาษาอังกฤษสำหรับการเขียน การเขียนโค้ด การค้นคว้า การสรุป และการวางแผน เครื่องมือนี้ออกแบบมาเพื่อรักษาข้อกำหนดที่ระบุชัดเจน ภาษาคำตอบที่ร้องขอ และข้อความตายตัวในเครื่องหมายอัญประกาศ

โมเดลจะได้รับคำสั่งให้ทำเป้าหมาย ข้อมูลนำเข้า และข้อจำกัดให้ชัดเจน จัดลำดับขั้นตอนที่มีประโยชน์ จัดการข้อมูลสำคัญที่ขาด และกำหนดวิธีตรวจสอบจากข้อกำหนดเดิม คำขอที่ชัดเจนอยู่แล้วควรแก้ไขให้น้อยที่สุดโดยไม่สร้างข้อกำหนดใหม่ PromptFinch แก้ไขคำสั่ง แต่ไม่ได้ทำงานที่คำสั่งนั้นระบุ โปรดตรวจสอบผลลัพธ์ เพราะคุณภาพขึ้นอยู่กับโมเดล การคลิกขวาเพียงอย่างเดียวจะไม่ส่งข้อความไปยังโมเดล

แอป macOS มีพื้นที่ทำงานและผู้ช่วยสำหรับข้อความที่เลือก: เลือกข้อความแล้วคลิกขวาในแอปที่รองรับ จากนั้นเลือก **Convert to English prompt** ในเมนูเสริมเพื่อแสดงแผงผลลัพธ์ มีพื้นที่ทำงานบนเบราว์เซอร์ด้วย การสร้างจริงต้องตั้งค่าคีย์ API ของโมเดล โหมดจำลองแสดงตัวอย่างขั้นตอนเท่านั้น ไม่แปลหรือปรับปรุงพรอมป์ต์

แอป macOS รองรับภาษาจีนตัวเต็ม (ค่าเริ่มต้น) อังกฤษ ญี่ปุ่น และเกาหลี หมายเหตุเกี่ยวกับการปรับปรุงและข้อสมมติที่สร้างใหม่จะใช้ภาษาของอินเทอร์เฟซ อินเทอร์เฟซเบราว์เซอร์ยังคงเป็นภาษาจีนตัวเต็ม และมีตัวเลือกภาษาของหมายเหตุแยกต่างหาก ลิงก์ใน README เปลี่ยนเฉพาะเอกสารเท่านั้น ผลลัพธ์ที่มีอยู่จะไม่ถูกเขียนใหม่เมื่อเปลี่ยนภาษา

**ขั้นตอน:** ป้อนหรือเลือก → สร้างพรอมป์ต์ภาษาอังกฤษ → ตรวจสอบผลลัพธ์
