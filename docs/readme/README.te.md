# PromptFinch

> ఈ పేజీలో పరిచయం యొక్క అనువాదం ఉంది. ఇన్‌స్టాలేషన్, API సహా పూర్తి సాంకేతిక పత్రం [English](../../README.md#english)లో అందుబాటులో ఉంది.

## PromptFinch పరిచయం

PromptFinch సాధారణ అవసరాల కోసం ప్రాంప్ట్‌లను సవరించి మెరుగుపరిచే సాధనం. ఏ భాషలోనైనా సూచనలను నమోదు చేయండి లేదా ఎంచుకోండి; రచన, కోడింగ్, పరిశోధన, సారాంశాలు, ప్రణాళికల కోసం ఆంగ్ల ప్రాంప్ట్‌లను రూపొందించండి. స్పష్టమైన అవసరాలు, కోరిన సమాధాన భాష, కొటేషన్ గుర్తుల్లోని స్థిరమైన వచనాన్ని కాపాడేలా ఇది రూపొందించబడింది.

లక్ష్యం, ఇన్‌పుట్‌లు, పరిమితులను స్పష్టీకరించమని, ఉపయోగకరమైన దశలను క్రమపరచమని, ముఖ్యమైన సమాచార లోటును పరిగణించమని, అసలు అవసరాల ఆధారంగా తనిఖీలను రూపొందించమని మోడల్‌కు సూచించబడుతుంది. ఇప్పటికే స్పష్టంగా ఉన్న అభ్యర్థనలకు కనీస మార్పులు చేయాలి; కొత్త అవసరాలను కల్పించకూడదు. PromptFinch సూచనలను సవరిస్తుంది; వాటిలో వివరించిన పనిని చేయదు. నాణ్యత మోడల్‌పై ఆధారపడుతుంది కాబట్టి ఫలితాన్ని సమీక్షించండి. కుడి క్లిక్ మాత్రమే చేస్తే వచనం మోడల్‌కు పంపబడదు.

macOS యాప్‌లో కార్యస్థలం, ఎంపిక సహాయకం ఉన్నాయి: అనుకూల యాప్‌లలో వచనాన్ని ఎంచుకుని కుడి క్లిక్ చేసి, సహాయక మెనూలో **Convert to English prompt** ఎంచుకుంటే ఫలితాల ప్యానెల్ కనిపిస్తుంది. బ్రౌజర్ కార్యస్థలం కూడా ఉంది. నిజమైన రూపొందింపుకు మోడల్ API కీని అమర్చాలి. నమూనా మోడ్ ప్రక్రియను మాత్రమే చూపిస్తుంది; అనువాదం లేదా మెరుగుదల చేయదు.

macOS యాప్‌లో సంప్రదాయ చైనీస్ (డిఫాల్ట్), ఆంగ్లం, జపనీస్ మరియు కొరియన్ అందుబాటులో ఉన్నాయి. మెరుగుదలలు, ఊహలకు సంబంధించిన కొత్త గమనికలు ఇంటర్‌ఫేస్ భాషలో రూపొందుతాయి. బ్రౌజర్ ఇంటర్‌ఫేస్ సంప్రదాయ చైనీస్‌లోనే ఉంటుంది; గమనికల భాషను వేరుగా ఎంచుకోవచ్చు. README లింకులు పత్రాలను మాత్రమే మారుస్తాయి. భాష మార్చినప్పుడు ఇప్పటికే ఉన్న ఫలితాలు తిరిగి రాయబడవు.
