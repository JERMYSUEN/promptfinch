# PromptFinch

> ఈ పేజీలో పరిచయం యొక్క అనువాదం ఉంది. ఇన్‌స్టాలేషన్, API సహా పూర్తి సాంకేతిక పత్రం [English](../../README.md#english)లో అందుబాటులో ఉంది.

## PromptFinch పరిచయం

PromptFinch సాధారణ అవసరాల కోసం ప్రాంప్ట్‌లను సవరించి మెరుగుపరిచే సాధనం. ఏ భాషలోనైనా సూచనలను నమోదు చేయండి లేదా ఎంచుకోండి; రచన, కోడింగ్, పరిశోధన, సారాంశాలు, ప్రణాళికల కోసం ఆంగ్ల ప్రాంప్ట్‌లను రూపొందించండి. స్పష్టమైన అవసరాలు, కోరిన సమాధాన భాష, కొటేషన్ గుర్తుల్లోని స్థిరమైన వచనం అలాగే ఉంటాయి.

macOS యాప్‌లో కార్యస్థలం, ఎంపిక సహాయకం ఉన్నాయి: అనుకూల యాప్‌లలో వచనాన్ని ఎంచుకుని కుడి క్లిక్ చేసి, సహాయక మెనూలో **Convert to an English Prompt** ఎంచుకుంటే ఫలితాల ప్యానెల్ కనిపిస్తుంది. బ్రౌజర్ కార్యస్థలం కూడా ఉంది. నిజమైన రూపొందింపుకు మోడల్ API కీని అమర్చాలి. నమూనా మోడ్ ప్రక్రియను మాత్రమే చూపిస్తుంది; అనువాదం లేదా మెరుగుదల చేయదు. UI సంప్రదాయ చైనీస్‌లో ఉంది; ఈ అనువాదం README పత్రం కోసం మాత్రమే.

**ప్రక్రియ:** నమోదు చేయండి లేదా ఎంచుకోండి → ఆంగ్ల ప్రాంప్ట్ రూపొందించండి → ఫలితాన్ని చూడండి
