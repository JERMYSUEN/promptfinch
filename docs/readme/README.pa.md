# PromptFinch

> ਇਸ ਪੰਨੇ ਉੱਤੇ ਜਾਣ-ਪਛਾਣ ਦਾ ਅਨੁਵਾਦ ਹੈ। ਇੰਸਟਾਲੇਸ਼ਨ ਅਤੇ API ਸਮੇਤ ਪੂਰਾ ਤਕਨੀਕੀ ਦਸਤਾਵੇਜ਼ [English](../../README.md#english) ਵਿੱਚ ਉਪਲਬਧ ਹੈ।

## ਪੰਜਾਬੀ

PromptFinch ਲਿਖਣ, ਕੋਡਿੰਗ, ਖੋਜ, ਸਾਰ ਬਣਾਉਣ ਅਤੇ ਯੋਜਨਾਬੰਦੀ ਲਈ ਪ੍ਰੌਂਪਟ ਸੰਪਾਦਕ ਅਤੇ ਸੁਧਾਰਕ ਹੈ। ਕਿਸੇ ਵੀ ਭਾਸ਼ਾ ਵਿੱਚ ਹਦਾਇਤਾਂ ਦਾਖ਼ਲ ਜਾਂ ਚੁਣ ਕੇ ਅੰਗਰੇਜ਼ੀ ਪ੍ਰੌਂਪਟ ਬਣਾਓ। ਇਹ ਸਪਸ਼ਟ ਲੋੜਾਂ, ਜਵਾਬ ਲਈ ਮੰਗੀ ਭਾਸ਼ਾ ਅਤੇ ਹਵਾਲਾ-ਚਿੰਨ੍ਹਾਂ ਵਿੱਚ ਦਿੱਤੇ ਸਥਿਰ ਟੈਕਸਟ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਣ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ।

macOS ਐਪ ਵਿੱਚ ਹੱਥੀਂ ਕੰਮ ਕਰਨ ਦੀ ਥਾਂ ਅਤੇ ਚੁਣੇ ਟੈਕਸਟ ਲਈ ਸਹਾਇਕ ਹੈ; ਅਨੁਕੂਲ ਐਪਾਂ ਵਿੱਚ ਟੈਕਸਟ ਚੁਣੋ, ਸੱਜਾ-ਕਲਿੱਕ ਕਰੋ, ਫਿਰ ਸਹਾਇਕ ਮੀਨੂ ਵਿੱਚ **Convert to English prompt** ਚੁਣ ਕੇ ਨਤੀਜੇ ਵੇਖੋ। ਬ੍ਰਾਊਜ਼ਰ ਵਰਕਸਪੇਸ ਵੀ ਉਪਲਬਧ ਹੈ। ਅਸਲ ਜਨਰੇਸ਼ਨ ਲਈ ਮਾਡਲ ਦੀ ਸੰਰਚਿਤ API ਕੁੰਜੀ ਚਾਹੀਦੀ ਹੈ। Mock ਸਿਰਫ਼ ਕਾਰਜ-ਪ੍ਰਵਾਹ ਦਿਖਾਉਂਦਾ ਹੈ, ਅਨੁਵਾਦ ਜਾਂ ਸੁਧਾਰ ਨਹੀਂ ਕਰਦਾ।

macOS ਦੇ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਇੰਟਰਫੇਸ ਲਈ ਰਵਾਇਤੀ ਚੀਨੀ (ਮੂਲ), ਅੰਗਰੇਜ਼ੀ, ਜਾਪਾਨੀ ਜਾਂ ਕੋਰੀਆਈ ਚੁਣੀ ਜਾ ਸਕਦੀ ਹੈ। ਬ੍ਰਾਊਜ਼ਰ ਦਾ ਇੰਟਰਫੇਸ ਰਵਾਇਤੀ ਚੀਨੀ ਵਿੱਚ ਹੀ ਰਹਿੰਦਾ ਹੈ। ਸੁਧਾਰਾਂ ਅਤੇ ਧਾਰਨਾਵਾਂ ਬਾਰੇ ਨੋਟ ਰਵਾਇਤੀ ਚੀਨੀ ਵਿੱਚ ਲਿਖਣ ਦੀ ਬੇਨਤੀ ਮਾਡਲ ਨੂੰ ਕੀਤੀ ਜਾਂਦੀ ਹੈ; ਇੰਟਰਫੇਸ ਦੀ ਭਾਸ਼ਾ ਬਦਲਣ ਨਾਲ ਉਹ ਅਨੁਵਾਦ ਨਹੀਂ ਹੁੰਦੇ। README ਦੇ ਭਾਸ਼ਾ ਲਿੰਕ ਸਿਰਫ਼ ਦਸਤਾਵੇਜ਼ਾਂ ਦੇ ਪੰਨੇ ਬਦਲਦੇ ਹਨ।

**ਕਦਮ:** ਦਾਖ਼ਲ ਕਰੋ/ਚੁਣੋ → ਪ੍ਰੌਂਪਟ ਬਣਾਓ → ਜਾਂਚੋ/ਕਾਪੀ ਕਰੋ।
