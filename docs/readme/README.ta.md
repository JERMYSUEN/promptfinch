# PromptFinch

> இந்தப் பக்கத்தில் அறிமுகத்தின் மொழிபெயர்ப்பு உள்ளது. நிறுவல் மற்றும் API உள்ளிட்ட முழுமையான தொழில்நுட்ப ஆவணம் [English](../../README.md#english) மொழியில் உள்ளது.

## PromptFinch அறிமுகம்

PromptFinch என்பது பொதுப் பயன்பாட்டுக்கான ப்ராம்ப்ட் திருத்தி மற்றும் மேம்படுத்தி. எந்த மொழியிலும் வழிமுறைகளை உள்ளிடலாம் அல்லது தேர்ந்தெடுக்கலாம்; எழுத்து, நிரலாக்கம், ஆராய்ச்சி, சுருக்கம், திட்டமிடல் ஆகியவற்றிற்கான ஆங்கில ப்ராம்ப்ட்களை உருவாக்கலாம். வெளிப்படையான தேவைகள், கோரப்பட்ட பதில் மொழி, மேற்கோள்களில் உள்ள நிலையான உரைகளைப் பாதுகாக்கும் வகையில் வடிவமைக்கப்பட்டுள்ளது.

நோக்கம், உள்ளீடுகள், கட்டுப்பாடுகளைத் தெளிவாக்கவும், பயனுள்ள படிகளை ஒழுங்கமைக்கவும், முக்கியமான தகவல் இடைவெளிகளைக் கையாளவும், அசல் தேவைகளிலிருந்து சரிபார்ப்புகளை உருவாக்கவும் மாதிரிக்கு அறிவுறுத்தப்படுகிறது. ஏற்கனவே தெளிவாக உள்ள கோரிக்கைகளில் குறைந்தபட்ச மாற்றங்களே செய்யப்பட வேண்டும்; புதிய தேவைகளை உருவாக்கக்கூடாது. PromptFinch வழிமுறைகளைத் திருத்துகிறது; அவற்றில் விவரிக்கப்பட்ட பணியைச் செய்யாது. தரம் மாதிரியைப் பொறுத்தது என்பதால் முடிவைச் சரிபார்க்கவும். வலது கிளிக் மட்டும் செய்தால் உரை மாதிரிக்கு அனுப்பப்படாது.

macOS செயலியில் பணியிடமும் தேர்வு உதவியாளரும் உள்ளன: இணக்கமான செயலிகளில் உரையைத் தேர்ந்தெடுத்து வலது கிளிக் செய்யவும்; துணை மெனுவில் **Convert to English prompt** என்பதைத் தேர்ந்தெடுத்தால் முடிவுப் பலகம் தோன்றும். உலாவிப் பணியிடமும் உள்ளது. உண்மையான உருவாக்கத்திற்கு மாதிரியின் API விசையை அமைக்க வேண்டும். மாதிரி விளக்கப் பயன்முறை செயல்பாட்டை மட்டும் காட்டும்; மொழிபெயர்க்கவோ மேம்படுத்தவோ செய்யாது.

macOS பயன்பாட்டில் பாரம்பரிய சீனம் (இயல்புநிலை), ஆங்கிலம், ஜப்பானியம் மற்றும் கொரியம் ஆகிய மொழிகள் உள்ளன. மேம்பாடுகள் மற்றும் அனுமானங்கள் பற்றிய புதிய குறிப்புகள் இடைமுக மொழியில் உருவாக்கப்படும். உலாவி இடைமுகம் பாரம்பரிய சீன மொழியிலேயே இருக்கும்; குறிப்புகளின் மொழியைத் தனியாகத் தேர்ந்தெடுக்கலாம்.
