# PromptFinch

> এই পাতায় পরিচিতির অনুবাদ রয়েছে। ইনস্টলেশন ও API-সহ সম্পূর্ণ প্রযুক্তিগত নির্দেশিকা [English](../../README.md#english)-এ পাওয়া যাবে।

## PromptFinch পরিচিতি

PromptFinch একটি সাধারণ উদ্দেশ্যের প্রম্পট সম্পাদক ও উন্নয়নকারী। যেকোনো ভাষায় নির্দেশ লিখুন বা নির্বাচন করুন এবং লেখা, কোডিং, গবেষণা, সারসংক্ষেপ ও পরিকল্পনার জন্য ইংরেজি প্রম্পট তৈরি করুন। স্পষ্ট চাহিদা, উত্তরের অনুরোধকৃত ভাষা এবং উদ্ধৃত নির্দিষ্ট পাঠ সংরক্ষণের জন্য এটি তৈরি করা হয়েছে।

macOS-এ কর্মক্ষেত্র ও নির্বাচন সহকারী রয়েছে: সমর্থিত অ্যাপে পাঠ নির্বাচন করে রাইট-ক্লিক করুন, তারপর সহায়ক মেনুতে **Convert to English prompt** বেছে নিলে ফলাফলের প্যানেল দেখা যায়। ব্রাউজার কর্মক্ষেত্রও আছে। প্রকৃত প্রম্পট তৈরিতে মডেলের API কী প্রয়োজন। মক মোড শুধু কার্যপ্রবাহ দেখায়; অনুবাদ বা উন্নয়ন করে না।

macOS-এর ইন্টারফেসে সেটিংস থেকে ঐতিহ্যবাহী চীনা (ডিফল্ট), ইংরেজি, জাপানি বা কোরীয় বেছে নেওয়া যায়। ব্রাউজারের ইন্টারফেস ঐতিহ্যবাহী চীনাতেই থাকে। উন্নয়ন ও অনুমানের নোট ঐতিহ্যবাহী চীনায় লেখার জন্য মডেলকে বলা হয়; ইন্টারফেসের ভাষা বদলালে সেগুলোর অনুবাদ হয় না। README-এর ভাষার লিংক শুধু নথির পাতা বদলায়।

**ধাপ:** লিখুন বা নির্বাচন করুন → ইংরেজি প্রম্পট তৈরি করুন → ফলাফল দেখুন
