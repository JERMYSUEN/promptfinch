# PromptFinch

> या पृष्ठावर परिचयाचे भाषांतर आहे. स्थापना आणि API यांसह संपूर्ण तांत्रिक माहिती [English](../../README.md#english) मध्ये उपलब्ध आहे.

## PromptFinch परिचय

PromptFinch हे सर्वसाधारण वापरासाठी प्रॉम्प्ट संपादन आणि सुधारणा करणारे साधन आहे. कोणत्याही भाषेत सूचना लिहा किंवा निवडा आणि लेखन, कोडिंग, संशोधन, सारांश व नियोजनासाठी इंग्रजी प्रॉम्प्ट तयार करा. स्पष्ट आवश्यकता, उत्तराची मागितलेली भाषा आणि अवतरणचिन्हांतील निश्चित मजकूर जतन करण्यासाठी हे तयार केले आहे.

macOS अ‍ॅपमध्ये कार्यक्षेत्र आणि निवड सहाय्यक आहे: सुसंगत अ‍ॅपमध्ये मजकूर निवडा, उजवे क्लिक करा आणि सहाय्यक मेनूमधून **Convert to English prompt** निवडा; त्यानंतर निकाल पॅनेल दिसते. ब्राउझर कार्यक्षेत्रही उपलब्ध आहे. प्रत्यक्ष निर्मितीसाठी मॉडेलची API की आवश्यक आहे. मॉक मोड फक्त प्रक्रिया दाखवतो; भाषांतर किंवा सुधारणा करत नाही.

macOS च्या सेटिंग्जमध्ये इंटरफेससाठी पारंपरिक चिनी (डीफॉल्ट), इंग्रजी, जपानी किंवा कोरियन भाषा निवडता येते. ब्राउझरचा इंटरफेस पारंपरिक चिनी भाषेतच राहतो. सुधारणा आणि गृहीतकांच्या नोंदी पारंपरिक चिनी भाषेत लिहिण्याची विनंती मॉडेलला केली जाते; इंटरफेसची भाषा बदलल्याने त्या अनुवादित होत नाहीत. README मधील भाषांचे दुवे फक्त दस्तऐवजाची पाने बदलतात.

**प्रक्रिया:** लिहा किंवा निवडा → इंग्रजी प्रॉम्प्ट तयार करा → निकाल पाहा
