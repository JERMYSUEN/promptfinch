# PromptFinch

> На цій сторінці перекладено вступ. Повна технічна документація доступна мовою [English](../../README.md#english).

PromptFinch — універсальний редактор і оптимізатор запитів. Вводьте або виділяйте інструкції будь-якою мовою, щоб отримати англомовний запит для написання текстів, програмування, досліджень, стислих викладів і планування. Інструмент розроблено для збереження явних вимог, запитаної мови відповіді та фіксованих рядків у лапках.

Моделі пропонується уточнити мету, вхідні дані й обмеження, упорядкувати корисні кроки, врахувати важливі прогалини в інформації та визначити перевірки на основі початкових вимог. Уже зрозумілі запити слід змінювати мінімально, не вигадуючи нових вимог. PromptFinch редагує інструкції, але не виконує описане завдання. Перевіряйте результат: якість залежить від моделі. Саме лише клацання правою кнопкою не надсилає текст моделі.

Застосунок macOS поєднує ручний робочий простір і помічника виділення; доступний також простір у браузері. Реальна генерація потребує налаштованого API-ключа моделі. Режим імітації показує процес без перекладу чи оптимізації.

Застосунок для macOS пропонує традиційну китайську (типово), англійську, японську та корейську мови. Нові примітки про вдосконалення та припущення створюються мовою інтерфейсу. Інтерфейс браузера залишається традиційною китайською й має окремий вибір мови приміток. Посилання в README змінюють лише документацію. Під час зміни мови наявні результати не переписуються.

**Процес:** виділити текст → клацнути правою кнопкою → вибрати **Convert to English prompt** → панель результатів (сумісні застосунки).
