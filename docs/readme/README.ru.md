# PromptFinch

> На этой странице переведено введение. Полная техническая документация доступна на [English](../../README.md#english).

PromptFinch — универсальный редактор и оптимизатор запросов. Вводите или выделяйте инструкции на любом языке, чтобы получить английский запрос для написания текстов, программирования, исследований, кратких изложений и планирования. Инструмент рассчитан на сохранение явных требований, запрошенного языка ответа и фиксированных строк в кавычках.

Модели предлагается уточнить цель, входные данные и ограничения, упорядочить полезные шаги, учесть важные пробелы в информации и вывести проверки из исходных требований. Уже ясные запросы следует изменять минимально, не придумывая новых требований. PromptFinch редактирует инструкции, но не выполняет описанную задачу. Проверяйте результат: качество зависит от модели. Сам по себе щелчок правой кнопкой не отправляет текст модели.

Приложение macOS объединяет ручную рабочую область и помощника выделения; доступна также версия в браузере. Реальная генерация требует настроенного API-ключа модели. Режим имитации показывает процесс без перевода или оптимизации.

Приложение для macOS поддерживает традиционный китайский (по умолчанию), английский, японский и корейский языки. Новые примечания об улучшениях и допущениях создаются на языке интерфейса. Интерфейс браузера остаётся на традиционном китайском и имеет отдельный выбор языка примечаний. Ссылки в README меняют только документацию. При смене языка существующие результаты не переписываются.

**Процесс:** выделить текст → щёлкнуть правой кнопкой → выбрать **Convert to English prompt** → панель результатов (совместимые приложения).
