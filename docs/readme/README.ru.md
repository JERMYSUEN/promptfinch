# PromptFinch

> На этой странице переведено введение. Полная техническая документация доступна на [English](../../README.md#english).

PromptFinch — универсальный редактор и оптимизатор запросов. Вводите или выделяйте инструкции на любом языке, чтобы получить английский запрос для написания текстов, программирования, исследований, кратких изложений и планирования. Инструмент рассчитан на сохранение явных требований, запрошенного языка ответа и фиксированных строк в кавычках.

Приложение macOS объединяет ручную рабочую область и помощника выделения; доступна также версия в браузере. Реальная генерация требует настроенного API-ключа модели. Режим имитации показывает процесс без перевода или оптимизации.

В настройках интерфейса macOS можно выбрать традиционный китайский (по умолчанию), английский, японский или корейский язык. Интерфейс браузера остаётся на традиционном китайском. Примечания об улучшениях и допущениях запрашиваются у модели на традиционном китайском и не переводятся при смене языка интерфейса. Языковые ссылки в README переключают только страницы документации.

**Процесс:** выделить текст → щёлкнуть правой кнопкой → выбрать **Convert to English prompt** → панель результатов (совместимые приложения).
