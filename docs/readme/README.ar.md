## العربية

PromptFinch محرّر عام للموجّهات ومحسّن لها، للكتابة والبرمجة والبحث والتلخيص والتخطيط. أدخل تعليمات بأي لغة أو حدّدها لإنشاء موجّه بالإنجليزية. صُمّم للحفاظ على المتطلبات الصريحة ولغة الإجابة المطلوبة والنصوص الثابتة بين علامتي اقتباس.

يُطلب من النموذج توضيح الهدف والمدخلات والقيود، وتنظيم الخطوات المفيدة، ومعالجة النواقص المهمة، واقتراح فحوص مستمدة من المتطلبات الأصلية. ينبغي إجراء تعديلات محدودة على الطلبات الواضحة، دون اختراع متطلبات جديدة. يحرّر PromptFinch التعليمات ولا ينفّذ المهمة الموصوفة فيها؛ راجع النتيجة، فالجودة تعتمد على النموذج. النقر بزر الفأرة الأيمن وحده لا يرسل النص إلى النموذج.

يوفّر تطبيق macOS مساحة للعمل اليدوي ومساعدًا للنص المحدّد؛ حدّد النص في تطبيق متوافق، وانقر بزر الفأرة الأيمن، ثم اختر **Convert to English prompt** من القائمة المرافقة لعرض النتائج. تتوفّر أيضًا مساحة عبر المتصفح. يتطلّب التوليد الفعلي مفتاح API مُعدًّا للنموذج. يعرض وضع Mock سير العمل دون ترجمة أو تحسين.

يوفّر تطبيق macOS الصينية التقليدية (الافتراضية) والإنجليزية واليابانية والكورية. تُنشأ ملاحظات التحسين والافتراضات الجديدة بلغة الواجهة. تظل واجهة المتصفح بالصينية التقليدية، مع خيار منفصل لاختيار لغة الملاحظات. تغيّر روابط README التوثيق فقط. لا تُعاد كتابة النتائج الموجودة عند تغيير اللغة.

**الخطوات:** أدخل التعليمات أو حدّدها، ثم ولّد الموجّه وراجعه وانسخه.
