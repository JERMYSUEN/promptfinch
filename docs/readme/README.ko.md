## PromptFinch 소개

PromptFinch는 범용 프롬프트 편집·최적화 도구입니다. 어떤 언어로든 지시를 입력하거나 선택해 글쓰기, 코딩, 조사, 요약, 계획에 사용할 영어 프롬프트를 생성합니다. 명시한 요구사항, 요청한 답변 언어, 따옴표로 지정한 고정 문자열을 보존하도록 설계되었습니다.

macOS 작업 공간과 선택 도우미를 제공하며, 호환 앱에서 텍스트를 선택하고 마우스 오른쪽 버튼을 누른 뒤 보조 메뉴에서 **영어 프롬프트로 변환**을 선택하면 결과 패널이 표시됩니다. 오른쪽 클릭만으로는 생성되지 않습니다. 브라우저 작업 공간도 있습니다. 실제 생성에는 모델 API 키 설정이 필요합니다. 모의 모드는 작업 흐름만 미리 보여주며 번역·최적화하지 않습니다.

macOS 인터페이스는 설정에서 중국어 번체(기본값), 영어, 일본어, 한국어 중 선택할 수 있습니다. 브라우저 인터페이스는 중국어 번체로 유지됩니다. 개선 사항과 가정에 관한 설명은 모델에 중국어 번체로 요청하며, 인터페이스 언어를 바꿔도 번역되지 않습니다. README의 언어 링크는 문서 페이지만 전환합니다.

**사용 흐름:** 입력·선택 → 영어 프롬프트 생성 → 결과 확인
