# PromptFinch

## PromptFinch परिचय

PromptFinch सामान्य प्रयोजन का प्रॉम्प्ट संपादक और अनुकूलक है। किसी भी भाषा में निर्देश लिखें या चुनें और लेखन, कोडिंग, शोध, सारांश तथा योजना के लिए अंग्रेज़ी प्रॉम्प्ट बनाएँ। यह स्पष्ट आवश्यकताओं, उत्तर की माँगी गई भाषा और उद्धृत निश्चित पाठ को सुरक्षित रखने के लिए बनाया गया है।

मॉडल को लक्ष्य, इनपुट और सीमाएँ स्पष्ट करने, उपयोगी चरण व्यवस्थित करने, ज़रूरी जानकारी की कमी पर ध्यान देने और मूल आवश्यकताओं से जाँच के तरीके निकालने के निर्देश दिए जाते हैं। पहले से स्पष्ट अनुरोधों में कम बदलाव होने चाहिए और नई आवश्यकताएँ नहीं गढ़ी जानी चाहिए। PromptFinch निर्देश संपादित करता है, उनमें बताई गई मूल समस्या हल नहीं करता। परिणाम की समीक्षा करें; गुणवत्ता मॉडल पर निर्भर करती है। केवल दायाँ क्लिक करने से पाठ मॉडल को नहीं भेजा जाता।

macOS कार्यक्षेत्र और चयन सहायक देता है: संगत ऐप में पाठ चुनें, दायाँ क्लिक करें और सहायक मेनू में **Convert to English prompt** चुनें; फिर परिणाम पैनल देखें। ब्राउज़र कार्यक्षेत्र भी उपलब्ध है। वास्तविक जनरेशन के लिए मॉडल API कुंजी चाहिए। मॉक मोड केवल प्रक्रिया दिखाता है; अनुवाद या अनुकूलन नहीं करता।

macOS ऐप में पारंपरिक चीनी (डिफ़ॉल्ट), अंग्रेज़ी, जापानी और कोरियाई उपलब्ध हैं। सुधार और मान्यताओं के नए नोट इंटरफ़ेस की भाषा में बनते हैं। ब्राउज़र इंटरफ़ेस पारंपरिक चीनी में ही रहता है और नोट की भाषा चुनने के लिए अलग विकल्प देता है। README के लिंक केवल दस्तावेज़ बदलते हैं। भाषा बदलने पर मौजूदा परिणाम दोबारा नहीं लिखे जाते।

**प्रक्रिया:** लिखें या चुनें → अंग्रेज़ी प्रॉम्प्ट बनाएँ → परिणाम देखें
