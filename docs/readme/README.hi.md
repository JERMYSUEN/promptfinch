> इस पृष्ठ पर परिचय का अनुवाद है। स्थापना और API सहित पूरा तकनीकी संदर्भ [English](../../README.md#english) में उपलब्ध है।

## PromptFinch परिचय

PromptFinch सामान्य प्रयोजन का प्रॉम्प्ट संपादक और अनुकूलक है। किसी भी भाषा में निर्देश लिखें या चुनें और लेखन, कोडिंग, शोध, सारांश तथा योजना के लिए अंग्रेज़ी प्रॉम्प्ट बनाएँ। स्पष्ट आवश्यकताएँ, उत्तर की माँगी गई भाषा और उद्धृत निश्चित पाठ सुरक्षित रहते हैं।

macOS कार्यक्षेत्र और चयन सहायक देता है: संगत ऐप में पाठ चुनें, दायाँ क्लिक करें और सहायक मेनू में **Convert to an English Prompt** चुनें; फिर परिणाम पैनल देखें। ब्राउज़र कार्यक्षेत्र भी उपलब्ध है। वास्तविक जनरेशन के लिए मॉडल API कुंजी चाहिए। मॉक मोड केवल प्रक्रिया दिखाता है; अनुवाद या अनुकूलन नहीं करता। UI पारंपरिक चीनी में है; यह अनुवाद केवल README के लिए है।

**प्रक्रिया:** लिखें या चुनें → अंग्रेज़ी प्रॉम्प्ट बनाएँ → परिणाम देखें
