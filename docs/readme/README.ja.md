## PromptFinchについて

PromptFinchは汎用のプロンプト編集・最適化ツールです。任意の言語で指示を入力・選択し、文章作成、プログラミング、調査、要約、計画向けの英語プロンプトを生成します。明示された条件、回答言語、引用された固定文字列を保持するように設計されています。

macOSでは作業スペースと選択アシスタントを利用でき、対応アプリでテキストを選択して右クリックし、補助メニューで **英語のプロンプトに変換** を選ぶと結果パネルが表示されます。右クリックだけでは生成されません。ブラウザ版も利用可能です。実際の生成にはモデルのAPIキー設定が必要です。モックモードは操作のプレビューのみで、翻訳・最適化は行いません。

macOS の表示言語は、設定で繁体字中国語（既定）、英語、日本語、韓国語から選べます。ブラウザ版の表示言語は繁体字中国語のままです。改善点と仮定の説明はモデルに繁体字中国語で要求しており、表示言語を変更しても翻訳されません。README の言語リンクで切り替わるのはドキュメントのページだけです。

**操作:** 入力・選択 → 英語プロンプトを生成 → 結果を確認
