# PromptFinch

<div dir="rtl">

> این صفحه ترجمهٔ معرفی پروژه است. راهنمای فنی کامل، شامل نصب و API، به زبان [English](../../README.md#english) در دسترس است.

## فارسی

PromptFinch ابزار عمومی ویرایش و بهینه‌سازی پرامپت برای نوشتن، برنامه‌نویسی، پژوهش، خلاصه‌سازی و برنامه‌ریزی است. دستورها را به هر زبانی وارد یا انتخاب کنید تا پرامپتی انگلیسی ساخته شود؛ برای حفظ الزامات صریح، زبان درخواستی پاسخ و عبارت‌های ثابت داخل گیومه طراحی شده است.

برنامهٔ macOS فضای کار دستی و دستیار متن انتخاب‌شده دارد؛ در برنامه‌های سازگار، روی متن انتخاب‌شده راست‌کلیک کنید، سپس **Convert to English prompt** را در منوی همراه انتخاب کنید تا نتایج نمایش داده شوند. فضای کار مرورگر نیز موجود است. تولید واقعی به کلید API پیکربندی‌شدهٔ مدل نیاز دارد. حالت Mock فقط روند کار را نمایش می‌دهد و ترجمه یا بهینه‌سازی نمی‌کند.

در تنظیمات رابط macOS می‌توانید چینی سنتی (پیش‌فرض)، انگلیسی، ژاپنی یا کره‌ای را انتخاب کنید. رابط مرورگر همچنان به چینی سنتی است. از مدل خواسته می‌شود توضیحات بهبودها و فرض‌ها را به چینی سنتی بنویسد؛ تغییر زبان رابط این توضیحات را ترجمه نمی‌کند. پیوندهای زبان در README فقط صفحهٔ مستندات را تغییر می‌دهند.

**روند کار:** دستورها را وارد یا انتخاب کنید، پرامپت بسازید، سپس بازبینی و کپی کنید.
