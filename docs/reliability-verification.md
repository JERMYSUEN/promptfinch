# 選取、貼回與主機驗證修正紀錄

日期：2026-10-09。這次針對既有 Brooks 審查的 D2、D3、D4 與 S1 修正，不是重新計算全專案評分。

## 已修正

- 浮動按鈕與右鍵選單都在明確點選時重新核對來源 App、欄位、文字、範圍、有效時間與忙碌狀態。按鍵、切換 App 或變更選取功能設定會取消待選操作。
- 文字資訊仍可供轉換；貼回必須有可信任、非空且長度相符的 UTF-16 範圍。明確空範圍及已知唯讀欄位拒絕貼回，無法確認位置時複製供手動使用。
- 模擬貼上只回報「已送出貼上操作」。剪貼簿還原完成後才更新狀態；新操作、複製、關閉或清除後，過期回呼不會覆蓋狀態或重新開窗。
- 剪貼簿備份不完整、暫存或立即還原失敗時，不自動複製覆寫原內容；貼上失敗期間的新複製內容也保留。結果可由使用者自行複製。
- 所有 HTTP 路徑先驗證 Host。預設只接受本機名稱與非萬用綁定主機的實際埠；代理部署必須明確設定 ALLOWED_HOSTS。Origin 需與可信任 Host 相符，不信任轉送主機標頭。Mac App 強制使用本機綁定並清空額外允許主機。

## 驗證限制及後續

本輪沒有呼叫付費模型，也沒有以自動測試讀取使用者一般剪貼簿、宿主文字或模擬貼入 IDE。Codex／Claude 的實體滑鼠、取字與全程貼回仍需分別驗收；系統送出按鍵不代表宿主一定接受。既有真人驗收屬於舊版本證據。

繁體中文衝突需求的最終組裝（D1）、重試總時間預算（D5）與完整 CI 流程仍待後續處理。這份紀錄不宣稱所有技術債已清除。
